## Features

| | |
|---|---|
| **Today dashboard** | A daily greeting, progress at a glance, today's tasks and a high-priority focus list. |
| **Task management** | Create, edit, complete and delete tasks, with text search, status filters and undo. |
| **Priorities & due dates** | Give every task a Low, Medium or High priority and an optional due date. |
| **Calendar** | A month view with task indicators, selectable days and a per-day task list. |
| **Daily notes** | One note for every day, saved automatically as you type, with a history of earlier days. |
| **Themes** | Light, Dark and System — Daymark adapts to your preference. |
| **Offline storage** | Tasks and notes are kept in a local SQLite database on your device. |
| **No account or subscription** | Nothing to sign up for, no cloud service and no subscription. |

---

## Privacy first

Daymark is built to keep your day to itself.

Daymark does not include cloud synchronisation, analytics or application-level data uploads. Your tasks and notes are stored locally. Device-level backup behaviour may depend on your Android settings.

- **Works offline** — every feature is available without a network connection.
- **No account required** — there is nothing to register for and nothing to remember.
- **No subscription** — Daymark is free to download and use.
- **Local by design** — tasks and notes are stored directly on your device.

## Testing and transparency

We believe in being clear about what has and has not been verified.

- **Windows:** the release build passed **16/16 functional UI automation tests**, covering task creation and completion, search, filters, undo, notes autosave, calendar, theme persistence, settings and data survival across a restart.
- **Windows signing:** the executable is **unsigned**, so SmartScreen may warn on first run.
- **Android:** the release APK completed **build, signature, alignment and manifest verification**.
- **Android runtime:** physical-device installation and runtime testing **have not yet been completed**. The app has not been run on a phone or emulator in this release cycle.
